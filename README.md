# Тестовое задание: Мини-сервис заметок (RESTful API + React-style UI)

### Стек технологий:
- **Backend:** Laravel 11 (PHP 8.4)
- **Database:** SQLite (Автономная, файл-база)
- **Frontend:** HTML5 + Нативный JS (Асинхронные запросы Fetch API)
- **Документация:** OpenAPI / Самодокументируемая спецификация
- **Окружение:** Docker (Docker Compose)

### Требования
- Установленный и запущенный Docker Desktop.

### Развертывание приложения (Одной командой)
Просто перейдите в папку проекта в терминале и запустите стандартную команду:
```bash
docker compose up -d
```
*Контейнер сам в фоновом режиме развернет структуру, скачает зависимости, создаст автономную базу SQLite и применит миграции заметок за 1-2 минуты. Процесс можно посмотреть командой*
```bash
docker compose logs -f
```

### Доступные адреса локально:
- **Основной интерфейс заметок:** [http://localhost](http://localhost)
- **Интерактивная документация API (Спецификация):** [http://localhost/api/documentation](http://localhost/api/documentation)

### Запуск автоматических тестов (PHPUnit)
Чтобы проверить работоспособность всех методов API и валидации, запустите:
```bash
docker compose exec laravel.test php artisan test
```
